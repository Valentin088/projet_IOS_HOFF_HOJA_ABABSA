# projet_IOSApp - Film & Série Box Office (SwiftUI + DuckDuckGo)

## Fonctionnalités
- Accueil : navigation vers **Films** ou **Séries**.
- Recherche de résultats “box office” via **DuckDuckGo** (endpoint JSON).
- Listes et page de détail.

## Note
- Les résultats DuckDuckGo peuvent varier selon l’API et les contenus renvoyés.
